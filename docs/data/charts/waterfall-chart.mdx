## Waterfall Chart

The waterfall chart takes in a vector for startValues (i.e. bar offsets), a vector for values, and a vector for labels.

### Error Handling

The waterfall fails gracefully when there is a vector size mismatch.

### Options

The waterfall chart may display the total of all values (opt-in).

The waterfall chart may invert axes (opt-in).
